# Training Dataset (AlphaEarth Embeddings)

This directory contains the preprocessed AlphaEarth embeddings used to train the mangrove classification model.

## Overview

- **Total files:** ~139 .npz files
- **Total size:** ~354 MB
- **Format:** Compressed NumPy arrays (244×244×64 float32)
- **Generated by:** Notebook `04_batch_download_embeddings.ipynb`

## File Naming Convention

```
cat{N}_id{X}_cov{Y}.npz
```

- `N`: Coverage category (1-5)
  - `cat1`: 1-20% mangrove coverage
  - `cat2`: 21-40% coverage
  - `cat3`: 41-60% coverage
  - `cat4`: 61-80% coverage
  - `cat5`: 81-100% coverage
- `X`: Unique sample ID
- `Y`: Exact coverage ratio (0.00 to 1.00)

## Data Structure

Each `.npz` file contains:

```python
{
    'data': ndarray(64, 244, 244) float32,  # AlphaEarth embedding bands
    'latitude_deg': float,                   # Center latitude (EPSG:4326)
    'longitude_deg': float,                  # Center longitude
    'year': int,                             # Data year (2020)
    'regionDiameter_p': int,                 # Region size in pixels (244)
    'spatialResolution_m': int,              # Spatial resolution (10m)
    'band_names': list[str],                 # ['A00', 'A01', ..., 'A63']
    'flipud_applied': bool,                  # Vertical flip flag
}
```

## Usage

This dataset is consumed by `model/dataset.py`:

```python
from model.dataset import MangroveDataset

dataset = MangroveDataset(
    path='input/dataset',
    categories=[1, 2, 3, 4, 5]
)
```

The model trains on these embeddings to predict mangrove coverage classes.

## Regeneration

To regenerate this dataset:
1. Ensure GMW shapefile is in `input/raw_data/gmw_v3_2020/`
2. Run `notebooks/pipeline/06_create_labels.ipynb` to generate metadata
3. Run `notebooks/pipeline/04_batch_download_embeddings.ipynb` to download embeddings

⚠️ **Warning:** Regeneration requires Google Earth Engine API access and may take several hours.
