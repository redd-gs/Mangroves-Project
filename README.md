# Mangrove Project

## Overview

This project proposes an end-to-end deep learning methodology that leverages **Google DeepMind's AlphaEarth Foundations**—a model that encodes multi-modal satellite observations (optical, SAR, LiDAR, thermal) from 2017 to 2024 into unified **64-dimensional per-pixel embeddings**—to refine existing mangrove maps.

Starting from **Global Mangrove Watch (GMW)** products as initial labels, we extract AlphaEarth embeddings for GMW-labeled mangrove pixels and complement them with locally sampled non-mangrove pixels (water and terrestrial vegetation). We then train a GPU-accelerated **Vision Transformer (ViT)** with self-attention to reclassify and refine the initial labels into **five graduated coverage classes** (1–20 %, 21–40 %, 41–60 %, 61–80 %, 81–100 %).

To ensure model interpretability, we integrate **Gradient-weighted Class Activation Mapping (Grad-CAM)**, which produces spatial heatmaps highlighting the regions that most influence the model's classification decisions—verifying that predictions rely on ecologically meaningful patterns such as water–vegetation boundaries, tidal channel morphology, and canopy density gradients.

The ViT is benchmarked against traditional ML baselines (Random Forest, XGBoost) and deep learning baselines (FCN, CNN), and predictions are qualitatively assessed against the National Parks Board mangrove mask on the Pulau Ubin study area.


## Pipeline

The complete workflow follows **six stages**, each documented in numbered notebooks:

1. **Label Extraction & Coverage Computation** — GMW v3 (2020) polygons are rasterised into 244 × 244 pixel chips (2 440 m × 2 440 m at 10 m resolution) centred on polygon centroids. Mangrove coverage ratio is computed and each chip is assigned to one of five discrete classes.
2. **Embedding Download** — For each chip, 64-dimensional AlphaEarth embeddings are retrieved from Google Earth Engine (`GOOGLE/SATELLITE_EMBEDDING/V1/ANNUAL`), producing 244 × 244 × 64 tensors.
3. **Dataset Construction** — Chips are sampled across South-East Asia with class balancing (equal samples per coverage class). Each sample pairs a 244 × 244 × 64 embedding tensor (input) with its coverage class (label), then split into train / val / test sets.
4. **Model Training** — A Vision Transformer is trained on embedding tensors with GPU acceleration via PyTorch Lightning (Adam optimiser, StepLR scheduler, model checkpointing on validation loss). Baseline models (FCN, CNN, Random Forest, XGBoost) are trained for comparison.
5. **Classification** — The trained model predicts five-class mangrove coverage on new, unseen embedding tiles, producing a refined map beyond binary presence/absence.
6. **Interpretability (Grad-CAM)** — Spatial heatmaps reveal which regions drive the model's decisions, ensuring plausibility and enabling expert review.

## Data Organization

### Input Data (`input/`)

All input data required for training and evaluation is organized in the `input/` directory:

**`input/dataset/`** — **Main training data** (139 files, ~354 MB)
- AlphaEarth embedding tensors (244 × 244 × 64, compressed NumPy `.npz` format)
- Each file encodes category and coverage: `cat{N}_id{X}_cov{Y}.npz`
  - `N`: Coverage category (1–5) → 1–20%, 21–40%, 41–60%, 61–80%, 81–100%
  - `X`: Unique sample ID
  - `Y`: Exact coverage ratio (0.00–1.00)
- Generated by [`create_labels.ipynb`](notebooks/create_labels.ipynb)


### External Data Sources

| Source | Format | How to obtain |
|--------|--------|---------------|
| **Global Mangrove Watch v3 (2020)** | Shapefile | [Download](https://www.globalmangrovewatch.org/) → place in `input/raw_data/gmw_v3_2020/` |
| **AlphaEarth Embeddings** | GEE: `GOOGLE/SATELLITE_EMBEDDING/V1/ANNUAL` | Downloaded programmatically via [`download_embeddings.ipynb`](notebooks/download_embeddings.ipynb) |
| **Sentinel-2 SR Harmonized** | GEE: `COPERNICUS/S2_SR_HARMONIZED` | Downloaded via GEE API |
| **GEE Project Key** | Text file | Create GEE project → save project ID in `input/raw_data/gee_credentials/` |
| **NParks Mangrove Mask** | PNG/JPG | Provided by NParks Singapore — for visual comparison only |

### Configuration Files (`config/`)

| File | Purpose |
|------|---------|
| `credentials.yml` | GEE project key + GMW shapefile path (fill in before running) |
| `training_datamodule.yml` | Dataset path (`input/dataset`), max_samples, batch_size, val/test split ratios |
| `training_litmodules.yml` | Model architecture (`ViTClassifier`), optimizer (Adam), LR scheduler, hyperparameters |
| `training_trainer.yml` | Epochs, GPU accelerator, callbacks (ModelCheckpoint, LRMonitor), TensorBoard logger |
| `test_datamodule.yml` | Test dataset path and parameters |
| `test_litmodule.yml` | Model architecture + checkpoint path for inference |

### Output Data (`output/`)

All model outputs and artifacts generated during training and evaluation:

**`output/checkpoints/`** — Trained model checkpoints
- `.ckpt` files (e.g., `best_model.ckpt`) saved by PyTorch Lightning
- Used for inference and model evaluation

**`output/predictions/`** — Inference results
- CSV or NPZ files with model predictions on new tiles

**`output/figures/`** — Generated visualizations
- Plots, Grad-CAM heatmaps, and analysis figures

## Project Structure (Folder-by-Folder)

### `input/` — All input data for the model
- **`dataset/`**: Main training data (139 .npz files with AlphaEarth embeddings)
- **`metadata/`**: CSV files with sample coordinates and coverage labels
- **`toy_dataset/`**: Synthetic GeoTIFFs for pipeline smoke-testing
- **`rgb_previews/`**: Sentinel-2 RGB preview images per coverage category
- **`raw_data/`**: External data you must provide (GMW shapefile, GEE credentials)
- **`templates/`**: Example file formats for custom data

### `model/` — Core Python package
- **`main.py`**: Full pipeline entry point (train, compare, inference, Grad-CAM)
- **`pipeline.py`**: Pipeline functions (baselines, inference, Grad-CAM generation)
- **`model_architectures.py`**: Classifier (FCN), CNNClassifier, ViTClassifier
- **`training_module.py`**: PyTorch Lightning wrapper with loss, metrics, logging
- **`dataset.py`**: MangroveDataset (.npz loader) + MangroveDataModule
- **`config_loaders.py`**: Config-driven factory (YAML → model/datamodule/trainer)
- **`grad_cam.py`**: Grad-CAM interpretability for CNN and ViT
- **`gee_collection.py`**: Google Earth Engine interface for AlphaEarth embeddings
- **`embedding_manager.py`**: Embeddings class (download, load, save .npz)
- **`geo_utilities.py`**: Region class for geodesic bounding boxes
- **`math_utilities.py`**: Haversine distance, geodesic circles
- **`constants.py`**: Project constants (resolution, bands, region size)
- **`data_transforms.py`**: Data augmentation transforms
- **`train.py`**: Legacy CLI entry point (kept for backward compatibility)

### `notebooks/` — Jupyter notebooks (exploration and data preparation)
- `explore_gmw.ipynb`: Explore GMW v3 2020 shapefile
- `download_embeddings.ipynb`: Download AlphaEarth 64-band embeddings
- `create_labels.ipynb`: Compute coverage labels, download embeddings, generate metadata
- `cosine_similarity_map.ipynb`: Cosine similarity heatmap across embedding bands
- `spatial_continuity_embeddings.ipynb`: Embedding spatial continuity analysis

### `config/` — YAML configuration files
- `credentials.yml`: GEE project key + GMW shapefile path
- `training_datamodule.yml`: Dataset path, batch size, train/val/test splits
- `training_litmodules.yml`: Model architecture, optimizer, LR scheduler
- `training_trainer.yml`: Epochs, GPU settings, callbacks, logger
- `test_datamodule.yml`: Test dataset configuration
- `test_litmodule.yml`: Model + checkpoint path for inference

### `output/` — Model outputs and artifacts
- **`checkpoints/`**: Trained model .ckpt files
- **`predictions/`**: Inference results (CSV/NPZ)
- **`figures/`**: Generated plots and Grad-CAM heatmaps

### `Writing_Sample/` — Research paper (LaTeX)
- Main paper, ViT architecture appendix, workflow diagrams, bibliography, figures

## Usage

### 1. Configure credentials

Edit `config/credentials.yml` with your GEE project key and GMW shapefile path:

```yaml
gee_project_key: "your-gee-project-id"
gmw_shapefile_path: "/path/to/gmw_v3_2020_vec.shp"
```

### 2. Run the full pipeline

```bash
python -m model.main \
    --credentials config/credentials.yml \
    --datamodule_config config/training_datamodule.yml \
    --litmodule_config config/training_litmodules.yml \
    --trainer_config config/training_trainer.yml \
    --train --run_baselines --run_inference --run_gradcam
```

This will:
1. Train the ViT model on the embedding dataset
2. Train and evaluate baselines (Random Forest, XGBoost, FCN, CNN)
3. Save a model comparison table to `output/predictions/baseline_comparison.csv`
4. Save confusion matrices to `output/figures/confusion_matrices.png`
5. Run inference on all tiles → `output/predictions/predictions.csv`
6. Generate Grad-CAM visualizations per category → `output/figures/gradcam/`

### 3. Run individual stages

```bash
# Train ViT only
python -m model.main --train \
    --datamodule_config config/training_datamodule.yml \
    --litmodule_config config/training_litmodules.yml \
    --trainer_config config/training_trainer.yml

# Baselines only (no Lightning training)
python -m model.main --run_baselines \
    --datamodule_config config/training_datamodule.yml \
    --litmodule_config config/training_litmodules.yml \
    --trainer_config config/training_trainer.yml

# Inference + Grad-CAM only (requires trained checkpoint)
python -m model.main --run_inference --run_gradcam \
    --datamodule_config config/training_datamodule.yml \
    --litmodule_config config/training_litmodules.yml \
    --trainer_config config/training_trainer.yml
```
